# Бот-кликер для Telegram Mini App

Автокликер для игры-кликера с уровнями. Работает на **Windows** и **macOS**.

## Логика работы

```
лвл 1 → клик по точке → пауза → лвл 2 → ... → лвл N (до какого)
→ клик "забрать деньги" → отдых → сброс на лвл 1 → повтор
```

- Один клик по калиброванной точке на каждом уровне (без скролла/движения).
- Забор денег — один клик по кнопке.
- После сбора — отдых (настраивается) — сброс на лвл 1 — новый цикл.
- Горячая клавиша toggle: вкл/выкл (по умолчанию `F8`).

## Установка

```bash
cd clicker_bot
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Использование

1. **Калибровка** — вкладка «Калибровка»:
   - выбери линию (левая / ручная / правая),
   - выбери уровень (или «Забрать деньги») в списке,
   - нажми «Калибровать выбранное» — окно свернётся, даст 15 сек:
     наведи курсор на нужную точку в игре и кликни ЛКМ.
   - повтори для каждого уровня и для кнопки забора.
2. **Настройки** — вкладка «Настройки»:
   - линия, до какого лвла, лвл забора, отдых после забора, задержка между кликами.
   - нажми «Сохранить настройки».
3. **Управление** — вкладка «Управление»:
   - «▶ Старт» / «■ Стоп» или горячая клавиша `F8`.

## Сборка в исполняемый файл

> PyInstaller собирает бинарник **только для той ОС, на которой запущен**.
> Поэтому `.exe` собирается на Windows, `.app` — на macOS. Готовые скрипты в проекте.

### Windows (.exe)

Запусти на Windows (двойной клик):

```bat
build_windows.bat
```

Создаст venv, поставит зависимости и соберёт `dist\clicker_bot.exe`.

Или вручную:
```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name clicker_bot main.py
```

### macOS (.app)

Запусти на macOS:

```bash
bash build_macos.sh
```

Создаст venv, поставит зависимости и соберёт `dist/clicker_bot.app`.

> **macOS:** в «Системные настройки → Конфиденциальность» дай разрешение
> на «Управление компьютером» (Accessibility), иначе клики не будут работать.

## Файлы

| файл | назначение |
|------|-----------|
| `config.py` | таблица уровней, настройки по умолчанию |
| `storage.py` | сохранение калибровок и настроек в `settings.json` |
| `calibrate.py` | логика калибровки точек по клику мыши |
| `bot_engine.py` | цикл кликов, забор, отдых (поток) |
| `hotkey.py` | глобальная горячая клавиша toggle |
| `main.py` | GUI (Tkinter) |

## Важно

- Не двигай мышью и не сворачивай игру во время работы бота.
- Координаты зависят от разрешения экрана и масштаба окна — калибруй заново при смене разрешения/окна.
- Используй на свой страх и риск — автоматизация сторонних игр может нарушать их правила.
